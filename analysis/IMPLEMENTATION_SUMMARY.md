## How to Reproduce All Results

### Step 1: Core Experiments (30-40 minutes)

```bash
python3 experiments/run_experiment.py experiments/supervised_gradient_hacking.yaml
python3 experiments/run_experiment.py experiments/rl_gradient_hacking.yaml
```

**Expected results:**
- Supervised deception gap: ~0.685
- RL deploy exit rate: ~0.35

### Step 2: Analysis Pipeline (1-2 minutes)

```bash
python3 analysis/collect_main_results.py
python3 analysis/supervised_behavior_breakdown.py
python3 analysis/gridworld_state_diff.py
python3 analysis/generate_results_figures.py
```

**Expected outputs:**
- `analysis/main_results_summary.csv`
- `analysis/supervised_summary.md`
- `analysis/supervised_behavior_breakdown.csv`
- `analysis/supervised_deception_by_feature.csv`
- `analysis/gridworld_state_diff.csv`
- `analysis/figures/plot1_supervised_comparison.png`
- `analysis/figures/plot2_rl_comparison.png`
- `analysis/figures/plot3_feature_breakdown.png`

### Step 3: Ablation Studies (3-4 hours, optional)

**Supervised ablations:**
```bash
python3 experiments/run_experiment.py experiments/supervised_ablation_no_manipulation.yaml
python3 experiments/run_experiment.py experiments/supervised_ablation_strength_0.05.yaml
python3 experiments/run_experiment.py experiments/supervised_ablation_strength_0.2.yaml
python3 analysis/supervised_ablation.py
```

**RL ablations:**
```bash
python3 experiments/run_experiment.py experiments/rl_ablation_strength_0.1.yaml
python3 experiments/run_experiment.py experiments/rl_ablation_strength_0.25.yaml
python3 experiments/run_experiment.py experiments/rl_ablation_stealth_0.4.yaml
python3 experiments/run_experiment.py experiments/rl_ablation_stealth_0.8.yaml
python3 analysis/rl_ablation.py
```

**Expected outputs:**
- `analysis/supervised_ablation_summary.csv` (5 rows: baseline, hacking, 3 ablations)
- `analysis/figures/supervised_deception_vs_strength.png`
- `analysis/rl_ablation_summary.csv` (6 rows: baseline, hacking, 4 ablations)
- `analysis/figures/rl_ablation_results.png`

## Fixes Applied

### Issue 1: Ablation Configs Had No Effect
**Problem:** All ablation runs showed identical results because hyperparameters weren't tracked.

**Fix:**
- Trainers now write hyperparameters to summary.json
- Experiment runner logs hyperparameters at start
- Analysis scripts read from summary files instead of hardcoding

**Verification:** Run two ablations with different strengths, check logs and summaries differ.

### Issue 2: Analysis Scripts Couldn't Find Results
**Problem:** Log paths didn't include `/hacking` subdirectory for ablation experiments.

**Fix:**
- Updated ablation analysis scripts to use correct paths
- Example: `supervised_ablation_no_manipulation/hacking/summary.json`

**Verification:** Run ablation analysis scripts, no "⚠ Warning: not found" messages.

### Issue 3: No Way to Verify Configs Were Different
**Problem:** No logging of hyperparameters made debugging impossible.

**Fix:**
- Added explicit logging at start of training
- Logs show exact values being used
- Easy to verify configs are actually different

**Verification:** Check training logs for "Gradient hacking hyperparameters:" section.
